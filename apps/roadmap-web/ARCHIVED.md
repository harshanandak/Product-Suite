# Roadmap Web archive

Roadmap Web is retained as historical source and is not a supported runtime,
workspace, deployment target, or CI surface. Its package manifest and lockfile
were removed so repository installs cannot resolve its former Next.js runtime.

The source and Supabase migrations remain for product recovery and immutable
database-history evidence. Database authority checks still classify changes to
the historical API, authentication, and migration paths as sensitive. Do not
run or deploy this directory from the current tree.

Use Git history before the retirement change to recover the former manifest,
lockfile, workflow, or build instructions if historical reproduction is ever
required.
